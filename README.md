# Isaac Authority

Онлайн **The Binding of Isaac: Repentance+** без задержки ввода.

Штатный онлайн игры — lockstep: каждый кадр ждёт ввод всех игроков, поэтому свой персонаж отвечает на клавиши с
задержкой 130–150 мс, а малейшее расхождение симуляций раскалывает лобби («десинк»). Isaac Authority берёт онлайн
самой игры — лобби, приглашения, старт матча, общий seed и общее сохранение — и меняет в нём только синхронизацию:

- **свой персонаж отвечает сразу** (19–42 мс) и принадлежит своему игроку: место, здоровье, слёзы, бомбы, питомцы;
- **мир принадлежит хосту**: враги, их снаряды, подбираемое, двери, сетка комнаты, зачистка, автоматы, счётчики;
- расхождение больше не раскалывает лобби: у остальных событие блокируется, а состояние приходит от того, чьё оно.

Состояние: **экспериментальная сборка для игры с друзьями.** Проверено на двух играх на одной машине; через Steam
между компьютерами — первые пробы. Ещё не синхронизируются лазеры врагов, лужи, шипы и ямы; в люк на следующий этаж
заходите вместе. Подробности и весь ход работы — в [PROJECT_STATUS.md](PROJECT_STATUS.md) и [docs/](docs/).

## Установка

Нужна игра в Steam, версия **v1.9.7.17.J460**, без модов (как и для штатного онлайна).

1. Скачать архив из [Releases](https://github.com/deaddarkus4/Isaac-Authority/releases), распаковать куда угодно.
2. Закрыть игру, запустить `INSTALL.cmd`. В папку игры кладутся два файла: `version.dll` и `IsaacAuthorityNative.dll`.
   Файлы самой игры не меняются; проверка файлов в Steam их не трогает.
3. Играть как обычно. Ничего запускать и останавливать не нужно.

Удаление — `UNINSTALL.cmd`.

## Как это ведёт себя в матче

- Модуль включается сам и **только в онлайн-матче, где он установлен у всех игроков** (одной и той же версии). Проще
  всего: Online → Friend Match по приглашению с друзьями, у которых он стоит.
- Если хоть у одного игрока модуля нет — матч остаётся полностью штатным: модуль ничего не меняет, даже сверку
  контрольных сумм, и через минуту перестаёт ждать. Одиночная игра, локальный кооператив и daily не затрагиваются.
- Состояние видно в заголовке окна игры: `Authority: waiting…`, `Authority: ON, host` / `ON, guest`,
  `Authority: off - причина`.
- Хост — игрок, которого игра пронумеровала первым (обычно создатель лобби). Вышел хост — хостом становится следующий;
  остались одни — модуль выключается, игра продолжается.
- Обмен между игроками идёт через Steam (тот же `steam_api.dll`, что уже загружен игрой): адреса и порты не нужны.
- Матч идёт на настоящих сохранениях. Модуль в них не пишет.
- Доверие: каждый игрок сам решает за своего персонажа, хост — за мир. Это для игры с друзьями, не против читеров.

Если что-то ведёт себя плохо, любое правило отключается при установке — у всех игроков одинаково:

```
powershell -ExecutionPolicy Bypass -File Install-IsaacAuthority.ps1 -Without lead,doors
```

Правила: `follow behaviour clear taken grid fire projectiles tears drops counters doors traps bombs hurt slots pets lead`.

## Сборка из исходников

Windows, Visual Studio с C++ (сборка 32-битная, как игра), CMake, Python 3 для стендов.

```powershell
.\scripts\Build-IsaacAuthority.ps1          # сборка и тесты
.\scripts\New-IsaacAuthorityRelease.ps1     # архив для установки: Binaries\release\
```

- `native/IsaacAuthority/src/native_adapter.cpp` — сам модуль; `version_proxy.cpp` — загрузчик, который игра грузит сама.
- `scripts/` — установщик, сборка, стенды на двух изолированных экземплярах игры (`Start-IsaacNativePair.ps1`,
  `Test-IsaacNative.py`, детектор расхождений `Watch-IsaacNativeDivergence.py`).
- `docs/` — исследования и отчёты по этапам, на русском; начать с
  [j460-native-online-reuse.md](docs/j460-native-online-reuse.md).
- `reverse/` — вспомогательные сценарии для разбора бинарника игры.

Адреса и смещения привязаны к сборке J460: после обновления игры модуль сам откажется включаться, пока их не
перепроверят.
