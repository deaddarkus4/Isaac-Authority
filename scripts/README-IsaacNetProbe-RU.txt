IsaacNetProbe 0.2.1 — запись диагностических событий

Подходит для Windows и оригинальной Repentance+ v1.9.7.17.J460.
EXE игры должен быть без патча IsaacOnlineModded.

УСТАНОВКА
1. Закрой игру и распакуй весь архив.
2. Запусти Install-IsaacNetProbe.cmd.
   Установщик найдёт игру во всех библиотеках Steam, в том числе на D:, E:
   и других дисках. Если игра не найдена или найдено несколько копий,
   появится окно выбора isaac-ng.exe.
3. Для игры с записью запускай ярлык Isaac Diagnostics на рабочем столе.
   Либо файл Start-IsaacDiagnostics.cmd в папке игры\IsaacNetProbe.
4. Загрузчик запускает игру через Steam. При ошибке появится сообщение;
   успешное подключение обозначается RECORDING READY.

Для явного указания нужной копии игры можно выполнить в PowerShell:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install-IsaacNetProbe.ps1 -GameExecutable "D:\SteamLibrary\steamapps\common\The Binding of Isaac Rebirth\isaac-ng.exe"

ПЕРВЫЙ ТЕСТ
Начни одиночный забег, перейди в соседнюю комнату и подбери предмет,
если он встретится. После этого выйди из игры. Запись настоящего
совместного забега проводится следующим шагом.

Журналы сохраняются здесь:
%LOCALAPPDATA%\IsaacNetProbe\logs
Путь последнего журнала также находится в:
%LOCALAPPDATA%\IsaacNetProbe\last-session.txt

Запуск обычным способом через Steam не включает запись автоматически.
Программа записывает сообщения движка с временными метками. Это пока
диагностика, не исправление рассинхронизации и не новый мультиплеер.
Запись полных пакетов, покадровых входов и внутренних характеристик
игроков в этой версии не реализована.

Файл игры и настройки модов установщик не меняет. Для удаления закрой
игру и удали папку IsaacNetProbe рядом с isaac-ng.exe, а также ярлык.
Сохранённые журналы могут содержать имена игроков, Steam ID и пути;
они никуда не отправляются автоматически.

Версия 0.2.1 обновляет определение пути; нативный модуль записи не изменён.
Файл IsaacPaths.ps1 должен оставаться рядом с файлами запуска и установки.
